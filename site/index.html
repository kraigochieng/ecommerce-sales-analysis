Jumbo · Global Operations · 2023–2025

A flat year, with one loud month.

Jumbo shipped 100,000 orders over three years. Almost every number held steady. Four things did not, and each one points to an action.

2025 at a glance

Sparklines show the 12 months of 2025. Changes compare full-year 2025 with full-year 2024. A change under 1% counts as flat.

Caveats and assumptions

  • One item per order. Each order holds one product type, so there is no basket or cross-sell analysis.
  • No repeat customers. Each customer ID appears once, so lifetime value and retention cannot be measured.
  • Revenue only. Cost of goods and shipping costs are missing, so the analysis covers top-line revenue, not profit.
  • Broad categories. Products are grouped into categories such as Fashion, which hides differences between single products.
  • Returns are yes or no. There are no return reasons or return dates.
  • One currency. All values are assumed to be in a single currency, with no exchange-rate effects.
  • Delivery in calendar days. Delivery time counts calendar days from order to delivery.

Source: synthetic e-commerce sales data, 100,000 orders. Built with SQLite and Python. Code on GitHub.
